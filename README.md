# THE WORLD — Monday 23 November 2026

A newspaper front page summing up 23 November 2026 world news: 35 stories from seven regions, plus a briefs column. The lead story is the collapse of the COP31 climate talks, the first COP failure since 2009.

## Files

- `entry.png` — the front page image, 1024x1024 PNG.
- `main.py` — the entry program; copies `entry.png` to `/output/entry.png`.
- `README.md` — this file.
- `LICENSE` — MIT license.

## How it works

`main.py` copies `entry.png` to `/output/entry.png`, checking first that the file is a valid PNG of at most 1 MiB, that its dimensions are exactly 1024x1024, and that the copied bytes match the original. The page was rendered locally with Playwright from an HTML layout — no AI image generator was used.
